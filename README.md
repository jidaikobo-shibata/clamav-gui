# clamav-gui

ClamAVを利用するデスクトップGUIです。Ubuntu版を開発中で、macOS・Windowsへの対応を予定しています。
ClamAV本体と定義ファイルは同梱せず、端末に導入されているClamAVを利用します。
CiscoまたはClamAVプロジェクトの公式アプリではありません。

## 現在の機能

- 基本フォルダー1つと除外条件からなる検査対象の保存・編集・複製・削除
- 対象ごとの手動検査と毎日・毎週・毎月の定期検査
- 対象→検査完了日時→ログの閲覧。脅威検出のある日時は太字
- ClamAVオプション20項目とサイズ上限2項目の環境設定
- 実行結果・使用設定の保存と、定期検査のデスクトップ通知

検出ファイルの自動削除・隔離は行いません。管理者権限を使った全体検査は未対応です。
開発版のため、実デスクトップでの通知表示・復帰時の予定実行は継続検証が必要です。

## Ubuntuでの開発

必要なもの：Python 3.10以降、GTK 4、PyGObject、ClamAV、更新済みの定義ファイル。
定期実行はユーザーsystemd、通知はnotify-sendを利用します。
Pythonの追加パッケージは不要です。GTKはOSパッケージを利用してください。
リポジトリのルートで起動します。

```bash
/usr/bin/python3 -m clam_gui
```

初回は対象が空です。「対象管理」から追加してください。
履歴・対象・環境設定はXDG_DATA_HOME配下のclamav-guiへ保存します。
既存の別アプリから設定・履歴・予定を自動で取り込みません。
検査オプションを変更したら保存してください。次回の手動・定期検査から反映されます。

```bash
/usr/bin/python3 -m unittest discover -s tests -v
```

GUIの分離検証にはWestonとdbus-run-sessionが必要です。
普段の画面・設定を使わずに検証します。

```bash
/usr/bin/python3 scripts/smoke_gui.py
```

## 定期実行

対象管理から予定を設定し、確認後にユーザーsystemd timerを登録します。
GUIを閉じても動作しますが、ログアウト中や電源オフ中の実行は保証しません。
既存のcron等は変更しません。同じ検査の二重登録を避けてください。
開発中はこのチェックアウトの絶対パスでCLIを登録するため、移動時は再登録が必要です。
