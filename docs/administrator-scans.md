# Ubuntuの管理者権限による手動検査

通常のGUI・定期検査・フォルダー監視は通常ユーザーで実行する。プランの操作メニューの「管理者権限で今すぐ検査…」だけが、対象確認後にpolkitの管理者認証を要求する。保存済みプランの実行権限や定期検査設定は変更しない。

## 導入するもの

- `/usr/libexec/clamav-gui-admin-scan`：管理者所有、0755の独立したPython補助プログラム。
- `/usr/share/polkit-1/actions/com.jidaikobo.ClamAVGui.admin-scan.policy`：管理者所有、0644の専用認証ポリシー。

`/usr/bin/pkexec`、`/usr/bin/clamscan`、`/usr/bin/bwrap`、既存の`libseccomp.so.2`を使用する。GUIをsudoで起動しない。利用者が編集できるプロジェクトのコードを管理者権限で実行しない。補助プログラムは`python3 -I`で起動し、アプリや利用者のPythonモジュールをインポートしない。

プロジェクト直下で次を実行すると、設置する実物とinstall.shを新しい一時ディレクトリへ出力する。準備スクリプトは昇格・システム設定変更を行わない。

```bash
/usr/bin/python3 scripts/prepare_admin_helper.py
```

出力されたディレクトリの補助プログラム・ポリシー・install.shを確認し、管理者の了承後にinstall.shを通常ユーザーのbashで実行する。中の2つのsudo installが管理者認証を求める。ポリシーの専用アクションは`auth_admin`を使用し、認証の一時保持は指定しない。組織・OSの追加ルールにより認証方法や要求条件が変わることはある。

補助プログラムを更新した場合も再設置する。GUIは導入先の所有者・書き込み権限・シンボリックリンク・現在のソースとの一致を確認し、未導入/古い場合は実行しない。補助プログラムやポリシーを削除する場合も管理者の承認が必要。一般利用者による書き換えを許可しない。

## 実行上の制限

- 固定されたClamAVと許可済み検査オプションだけを受け付ける。シェル、任意コマンド、削除・隔離・任意のDBやログ保存先の指定は受け付けない。
- 対象・除外・オプションは上限4096バイトのJSONで渡す。設定が大きすぎる場合はプランを分ける。
- `/proc`・`/sys`・`/dev`・`/run`は対象に指定できず、配下にあっても除外する。別ファイルシステムへ自動で進まない。検査したい別ファイルシステムは明示的な対象として追加する。
- bubblewrapでホストのファイルシステムを読み取り専用にし、実デバイスを公開しない。専用の一時フォルダーのみ書き込み可能にする。ネットワーク/PID名前空間を分離し、読み取り用の能力以外は落とす。libseccompでソケット作成・接続・ptrace・mount等を禁止する。隔離に失敗した場合は制限なしでの再実行をしない。
- 実行中は`/run/clamav-gui-admin-scan.lock`を管理者所有で使用し、管理者検査同士の競合を拒否する。通常の全体検査の実行待ち・ロックも継続利用する。
- `/var/tmp`に管理者所有の専用一時領域を作り、終了時に片付ける。GUIの中止要求・通信切断・終了を受けて補助プログラムが検査を停止する。
- 検査結果は通常権限のGUIへ標準出力で返す。利用者のSQLiteや出力先を管理者プロセスから開かない。GUI側で管理者手動検査と分かる記録を残し、通常の結果表示・通知を使う。
- 管理者であっても暗号化、サイズ上限、セキュリティ機構等によって検査できない内容はある。システム侵害がないことを証明する機能ではない。

## 確認状況

要求の検証、許可されない引数の拒否、フィルター生成、通信切断時の停止、認証キャンセルの履歴、GUIの確認・開始処理を管理者権限なしでテストする。実際のpolkit認証、rootでの読み取り、bubblewrapの隔離動作は設置承認後に実機で確認する。初回は小さな専用テストフォルダーを使う。
